# Zapret Desktop — отчёт по фазе 0

Дата: 10 ноября 2026 года. Репозиторий: `mournami/zapret13231`.
Ветка: `codex/desktop-app`. Проверенный коммит:
`91a64103f8e405056a6b8a434bbdc4d7835d45c6`.

Программные изменения фазы 0 выполнены. Обязательный Windows CI прошёл на
указанном выше коммите, включая сборку и установку приложения, IPC и реальный
запуск/остановку winws с WinDivert. Ручная проверка на Windows-компьютере и
проверка обхода блокировок у провайдера ещё не выполнены. Коммерческая готовность
приложения не подтверждена. Фаза 1 не начата.

В ходе подготовки этого отчёта повторно сверены состояние Git, статусы GitHub
Actions и сохранённые логи локальных проверок. Перед коммитом отчёта повторены
локальные fmt, clippy, workspace-тесты, проверка и сборка UI: все прошли;
15 Rust-тестов, 0 ошибок и предупреждений svelte-check. Windows-результаты ниже
относятся к указанному выше коммиту. Программный код при публикации отчёта не менялся.

В фазе 0 принята архитектура v2 из `docs/ARCHITECTURE.md`. Реализованы следующие
изменения:

| Область | Результат |
| --- | --- |
| API | В `zapret-core::api` описаны фиксированные команды, ответы, Snapshot, Operation и ProbeResult. Имена существующих полей UI сохранены. |
| Контракты | Rust-генератор через schemars и ts-rs создаёт JSON Schema и TypeScript. `ui/src/types.ts` реэкспортирует сгенерированные типы. CI проверяет отсутствие diff. |
| Подбор | Запуск проб, подбор, отмена и состояние операции перенесены из Tauri в `zapretd`. Сохранены базовая проверка без обхода, два успешных прохода и восстановление исходной настройки. |
| Восстановление | Файл `selection-recovery.json` хранится в данных службы в ProgramData. Демон пытается восстановить настройку при запуске; ошибка восстановления отражается в snapshot. |
| GUI | Tauri пересылает действия демону. Установка службы и сохранение JSON-отчёта остаются в GUI; пользовательский путь не передаётся демону. Дизайн сохранён. |
| Движок и платформа | Добавлен Engine; текущая логика winws вынесена в адаптер, SCM и named pipe — в Windows-модуль. На неподдерживаемых ОС возвращается явная ошибка. |
| Транспорт UI | Добавлены Tauri- и HTTP-транспорты. HTTP-вариант с Bearer-токеном подготовлен, но к UI не подключён; HTTP-сервер не добавлялся. |
| Golden-фикстуры | Закреплены 22 исходных `.bat` Flowseal 1.10.4, результат существующего импорта и итоговые аргументы winws. Rust-тест проверяет загрузчик и разрешение путей. `.bat` не исполняются. |
| CI | Windows job обязателен в workflow. macOS job запускается только вручную с явным выбором и не блокирует Windows. |

Подбор по сервисам, композиты, периодический Doctor, обновление бандла, zbuild
и Rust-парсер `.bat` не добавлялись. Python-импортёр и `engines/macos/` сохранены
без изменений.

Всего на Windows прошли 14 тестовых запусков: 13 workspace-тестов и один тест
установленной службы. Последний подтвердил начальное выключенное состояние,
чтение snapshot и каталога, отказ на некорректные команды и параметры, включение
движка, статус running, остановку и получение отчёта.

Перед коммитами также выполнялись локальные fmt, clippy, workspace-тесты и
проверки UI. Последний сохранённый локальный результат: 15 Rust-тестов на macOS,
0 ошибок и предупреждений svelte-check, успешная frontend-сборка. Контролируемые
тесты покрывают отмену, два подтверждения, откат, ошибку запуска, сохранение файла
при неудачном восстановлении и продолжение операции после освобождения вызывающей
стороной своего объекта. Физическая проверка закрытия GUI остаётся отдельным пунктом.

При локальной подготовке были выявлены ограничения окружения: Nix-обёртка
C-компилятора ошибалась на кириллическом пути; проверки прошли с Apple clang.
Полная Windows cross-проверка демона упиралась в отсутствие заголовков Windows SDK.
Позднее нативные сборка и clippy на Windows прошли. Сохраняется предупреждение
ts-rs о `deny_unknown_fields`: Rust-десериализация продолжает применять атрибут,
отказ на лишние поля проверен тестом.

Тестовый установщик доступен в
[Artifacts первого успешного run](https://github.com/mournami/zapret13231/actions/runs/42841680373/artifacts/13777651209).
Это сборка для разработки без подписи издателя. Релиз не публиковался.

**Ухудшение на macOS:** текущий Rust API не поддерживается, поэтому из GUI
недоступны подбор, пробы, enable/disable, Doctor и отчёт. Замороженный Go-движок
сохранён; адаптер macOS отложен до фазы 5. macOS job в этих двух run пропущен,
результат сборки или работы Mac-приложения ими не подтверждается.
