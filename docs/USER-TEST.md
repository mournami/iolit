# Проверка тестовой сборки

Это сборка для проверки, пока без подписи издателя. Коммерческий выпуск ещё не готов.
На Windows нужен x64-компьютер; текущий Mac-пакет собран для Apple Silicon.

1. Установите приложение: `.exe` на Windows, `.pkg` на Mac. Права администратора
   нужны для системной службы. Пароль вводится только в штатном окне системы.
   На Windows сборка не подписана: в окне SmartScreen нажмите «Подробнее» →
   «Выполнить в любом случае», затем «Да» в запросе прав. Установщик сам
   покажет ход установки и откроет приложение, нажимать больше ничего не нужно.
2. Откройте приложение. После новой установки обход должен быть выключен.
3. Нажмите «Включить обход». Статус «Движок запущен» подтверждает запуск,
   а доступность сервисов проверяется отдельно.
4. Запустите «Проверить». HTTPS-проверка YouTube относится к сайту; STUN проверяет
   конкретный UDP-сервер. Они не заменяют воспроизведение видео и голосовой звонок.
5. Откройте YouTube и посмотрите видео несколько минут с перемоткой. Затем
   проверьте приём и передачу голоса в обычном голосовом канале Discord.
6. Нажмите «Отключить» и убедитесь, что обычный интернет продолжает работать.
7. Отдельно проверьте перезапуск компьютера при включённом и выключенном обходе:
   выбранное состояние должно сохраняться.
8. При проблеме сохраните отчёт на странице «Диагностика». Отчёт не включает
   сырые журналы, IP-адреса и ваш список доменов. Сообщите также, какая именно
   функция не сработала: сайт, видео, входящий или исходящий голос.

Если стандартные проверки проходят без обхода, приложение сохраняет исходную
настройку. Это не доказывает, что любое видео или голосовой сервер также доступны.

Закрытие окна или выход из интерфейса не заменяют кнопку «Отключить»: системная
служба управляет обходом независимо от окна приложения.

## YouTube или Discord не проходят проверку из-за DNS

Если в «Проверке» написано «не удалось получить адрес сервера (DNS)» или
«Этот хост неизвестен», компьютер не может узнать адрес сайта. Обход меняет
только пакеты и такую ошибку не исправит: обычно DNS подменяет или блокирует
провайдер. Если Discord то работает, то нет даже при выключенном обходе, это
тоже признак проблем у провайдера.

В Windows 11 проще всего нажать «Включить» в подсказке на странице «Проверка»
или в «Настройки» → «Защищённый DNS»: приложение само поставит Cloudflare
`1.1.1.1` с DNS через HTTPS на активные подключения и запомнит прежние
настройки. «Выключить» там же или удаление программы вернут их.

Вручную (адреса Cloudflare, можно взять и другие публичные DNS):

- **Windows 11:** «Параметры» → «Сеть и Интернет» → ваше подключение (Ethernet
  или Wi-Fi) → «Назначение DNS-сервера» → «Изменить» → «Вручную», включите IPv4,
  предпочитаемый DNS `1.1.1.1`, дополнительный `1.0.0.1`, шифрование DNS —
  «Только зашифрованный (DNS через HTTPS)». То же для IPv6: `2606:4700:4700::1111`
  и `2606:4700:4700::1001`.
- **Windows 10:** «Панель управления» → «Центр управления сетями» → «Изменение
  параметров адаптера» → свойства подключения → «IP версии 4» → «Использовать
  следующие адреса DNS-серверов»: `1.1.1.1` и `1.0.0.1`. Шифрования DNS в
  настройках Windows 10 нет; включите его в браузере.
- **Браузер:** Chrome и Edge — «Настройки» → «Конфиденциальность и безопасность» →
  «Использовать безопасный DNS» → Cloudflare. Firefox — «Настройки» → «Приватность
  и защита» → «DNS через HTTPS» → «Максимальная защита».

Если компьютер в рабочей сети или на нём есть VPN, сначала уточните у
администратора: свой DNS может сломать доступ к внутренним ресурсам. После
смены DNS запустите «Проверку» снова.
